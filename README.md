# SQL Data Cleaning Project

This project focuses on cleaning a shipment dataset using PostgreSQL.

## Tasks Performed

* Removed duplicate records
* Handled NULL values using COALESCE()
* Trimmed extra spaces using TRIM()
* Standardized text formatting using INITCAP() and UPPER()
* Fixed negative values using ABS()
* Calculated transit days


## Tools Used

* PostgreSQL
* SQL


## Files Included

* clean_dataset.sql
* dirty_shipments.xlsx
* project output image

## Key SQL Functions Used

* COALESCE()
* ABS()
* ROW_NUMBER()
* TRIM()
* INITCAP()
* UPPER()
